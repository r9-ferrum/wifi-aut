# Captive Portal для Noctalia

Плагин для Noctalia 4.6.6 или новее. Каждые 20 секунд запрашивает у NetworkManager состояние подключения. При состоянии `portal` показывает уведомление и автоматически открывает http://neverssl.com/ в браузере по умолчанию: сеть должна перенаправить этот HTTP-запрос на страницу входа. Кнопка с глобусом на панели позволяет открыть страницу повторно.

Уведомление и автоматическое открытие выполняются один раз для текущего набора активных подключений. После восстановления интернета или отключения сети обнаружение включается снова. Уведомление само по себе не содержит кнопки действия.

## Установка из GitHub одной командой

Разместите содержимое этой папки в корне отдельного репозитория GitHub, включая `install.sh`. Замените `OWNER/REPO` в команде на адрес своего репозитория. Это шаблон: репозиторий пока не опубликован.

Нужен `git`. Команда скачивает репозиторий во временную папку, запускает установщик и удаляет временный клон:

```bash
(bash -c 'set -e; work=$(mktemp -d); trap '\''rm -rf -- "$work"'\'' EXIT; git clone --depth 1 https://github.com/OWNER/REPO.git "$work/repo"; bash "$work/repo/install.sh"')
```

Повторный запуск обновляет плагин, сохраняя предыдущую папку рядом с суффиксом `.backup.*`. Установщик запускайте обычным пользователем. На CachyOS он предложит через `sudo pacman` установить отсутствующие NetworkManager, libnotify и xdg-utils. Службы и сетевые настройки автоматически не меняются.

По умолчанию используется `${XDG_CONFIG_HOME:-$HOME/.config}/noctalia/plugins/captive-portal`. Путь вашей версии Noctalia здесь не подтверждён. Если он отличается, задайте `NOCTALIA_PLUGIN_DIR` — родительскую папку плагинов — перед запуском команды. После установки перезапустите Noctalia и включите плагин вручную: установщик не перезаписывает настройки оболочки.

Для проверки файлов и зависимостей без установки: `bash install.sh --check`.

## Установка на ноутбук

Нужны установленная Noctalia, работающий NetworkManager, `nmcli`, `notify-send` (пакет libnotify) и `xdg-open` (пакет xdg-utils).

```bash
sudo pacman -S --needed networkmanager libnotify xdg-utils
```

Скопируйте эту папку `captive-portal` в пользовательский каталог плагинов вашей версии Noctalia. Обычно это `~/.config/noctalia/plugins/`, но в доступном окружении путь установки подтвердить не удалось. Итоговая папка должна содержать manifest.json, Main.qml и BarWidget.qml непосредственно внутри captive-portal.

Перезапустите Noctalia, включите Captive Portal в настройках плагинов. Добавьте его виджет в настройки панели, если нужна кнопка повторного открытия страницы.

## Проверка в публичной сети

```bash
nmcli networking connectivity check
```

При необходимости авторизации NetworkManager должен вернуть `portal`. Затем в течение примерно 20 секунд плагин покажет уведомление и откроет браузер. Завершите авторизацию; состояние должно стать `full`.

Если выводится `unknown` или `limited`, автоматическое открытие не сработает: проверьте настройки connectivity checking NetworkManager. Плагин намеренно не считает любую неисправность интернета страницей авторизации. VPN, собственный DNS и особенности сети могут мешать обнаружению; кнопка на панели открывает HTTP-страницу вручную.

Настройки плагина: `autoOpen` (по умолчанию true) и `intervalSeconds` (по умолчанию 20, минимум 10). Отдельной графической страницы настроек нет.

## Статус проверки

Проверены JSON-манифест и наличие файлов entryPoints. Запуск в Noctalia и реальной captive-сети не проверен: в доступном окружении нет Noctalia/Quickshell, NetworkManager и инструментов проверки QML. Совместимость с установленной на ноутбуке версией требует проверки при установке.
