# WiFi Aut — Captive Portal для Noctalia 5

Плагин для Noctalia 5.4.0 (plugin API 43): уведомляет об авторизации в публичном Wi-Fi и открывает http://neverssl.com/ в браузере. Авторизацию пользователь проходит самостоятельно.

## Установка

Установка одной командой из GitHub:

```bash
sudo pacman -S --needed git && bash -c 'set -e; work=$(mktemp -d); trap '\''rm -rf -- "$work"'\'' EXIT; git clone --depth 1 https://github.com/r9-ferrum/wifi-aut.git "$work/repo"; bash "$work/repo/install.sh"'
```

Команду запускайте в обычном терминале от своего пользователя, без `sudo` перед `install.sh`. Она сама скачивает `main` во временную папку, проверяет плагин и устанавливает его.

Установка из уже скачанного каталога:

```bash
bash install.sh
```

Установщик проверяет манифест, устанавливает зависимости через pacman при необходимости, копирует плагин в `${XDG_DATA_HOME:-$HOME/.local/share}/noctalia/plugins/captive-portal`, перезагружает конфигурацию Noctalia и включает `r9-ferrum/captive-portal`. Не запускайте через sudo или внутри Flatpak: там могут отличаться XDG-пути и доступные команды.

В настройках панели добавьте виджет Captive Portal (portal). Нажатие на глобус открывает окно состояния, ручной проверки и входа. Кнопка «Настройки интервалов» открывает стандартные настройки плагина, которые Noctalia сохраняет автоматически.

Для другого родительского каталога плагинов задайте NOCTALIA_PLUGIN_DIR. Предыдущая установка сохраняется в соседнем каталоге plugins-backups, вне каталога обнаружения плагинов.

Проверка без установки:

```bash
bash install.sh --check
```

## Поведение

- Обычный интервал проверки: 20 секунд (10–86400).
- После full: только локальный опрос активных подключений каждые 300 секунд (30–86400), без запуска connectivity check.
- Смена набора ActiveConnection возобновляет проверку, включая переподключение к тому же профилю и изменения VPN.
- При portal: уведомление и автоматическое открытие браузера один раз для текущего набора подключений; autoOpen можно отключить.
- Кнопка «Проверить сейчас» выполняет проверку даже после full.
- Панель показывает имена активных подключений (включая проводные и VPN), последний результат, время проверки и ошибки.
- После full истечение авторизации в той же сессии автоматически не определяется. Используйте ручную проверку или переподключение.

NetworkManager должен работать с включённой проверкой подключения. Собственные фоновые проверки NetworkManager плагин не отключает. VPN, DNS и особенности сети могут мешать обнаружению портала. Если сеть не перенаправляет HTTP-запрос, neverssl.com может не открыть страницу входа.

## Диагностика

```bash
noctalia msg plugins list
```

```bash
nmcli networking connectivity check
```

```bash
noctalia msg plugin r9-ferrum/captive-portal:service all check
```

## Перенос с QML

Версия 2.0.0 использует plugin.toml и service.luau / widget.luau / panel.luau. Старые Main.qml, BarWidget.qml, Panel.qml и manifest.json оставлены как исходники прежней версии; установщик их больше не копирует. Старый каталог ~/.config/noctalia/plugins/captive-portal не используется новой версией. Старые настройки QML автоматически не импортируются.

Линтер проверяет манифест и обращения к настройкам. Работа в реальной сети с captive portal требует отдельной проверки.
