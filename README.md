# WiFi Aut — Captive Portal для Noctalia

Плагин для **Noctalia Shell**, который уведомляет о необходимости авторизации в публичной Wi-Fi сети и открывает страницу входа в браузере. Подходит для сетей университетов, аэропортов, гостиниц и кофеен.

Разрабатывается для CachyOS / Arch Linux с NetworkManager. Требуется Noctalia **4.6.6 или новее**.

## Возможности

- Проверка состояния подключения каждые 20 секунд.
- Уведомление при обнаружении captive portal — страницы авторизации в сети.
- Автоматическое открытие браузера при необходимости входа.
- Кнопка с глобусом на панели для повторного открытия страницы.
- Обновление повторным запуском установщика с резервной копией предыдущей версии.

Плагин открывает страницу входа; авторизацию пользователь проходит самостоятельно.

## Установка одной командой

Выполните в обычном терминале ноутбука от своего пользователя:

```bash
sudo pacman -S --needed git && bash -c 'set -e; work=$(mktemp -d); trap '\''rm -rf -- "$work"'\'' EXIT; git clone --depth 1 https://github.com/r9-ferrum/wifi-aut.git "$work/repo"; bash "$work/repo/install.sh"'
```

Команда скачает репозиторий во временную папку и запустит установщик. На CachyOS / Arch Linux установщик при необходимости запросит через `sudo pacman` установку пакетов `networkmanager`, `libnotify` и `xdg-utils`.

После установки:

1. Перезапустите Noctalia Shell.
2. Включите **Captive Portal** в настройках плагинов.
3. Добавьте виджет плагина на панель, если нужна кнопка ручного открытия страницы.

NetworkManager должен быть запущен, а проверка подключения к интернету — включена. Установщик не меняет настройки сети и не запускает службы автоматически.

### Каталог установки

По умолчанию файлы устанавливаются в:

```text
${XDG_CONFIG_HOME:-$HOME/.config}/noctalia/plugins/captive-portal
```

Проверьте каталог плагинов своей версии Noctalia: этот путь пока не подтверждён запуском в оболочке. Для другого каталога задайте переменную `NOCTALIA_PLUGIN_DIR`, указав родительскую папку плагинов, перед запуском установщика.

Не запускайте установщик целиком через `sudo`: плагин устанавливается для текущего пользователя. Запускайте команду в терминале ноутбука, поскольку изолированное окружение другого приложения может использовать собственный `XDG_CONFIG_HOME`.

## Как это работает

Плагин запрашивает у NetworkManager результат проверки подключения. Если NetworkManager возвращает `portal`, появляется уведомление и браузер открывает [http://neverssl.com/](http://neverssl.com/).

Публичная сеть обычно перехватывает этот HTTP-запрос и перенаправляет браузер на свою страницу входа. Поэтому адрес портала заранее знать не требуется: например, сеть университета может перенаправить запрос на собственный домен авторизации.

Если сеть не перенаправляет HTTP-запросы, этот способ не откроет её портал автоматически. Настройка собственного адреса входа в текущей версии не предусмотрена.

Уведомление и автоматическое открытие выполняются один раз для текущего набора активных подключений. После `full` плагин прекращает запускать проверку интернета до смены подключений. После `full` раз в 5 минут выполняется только локальный запрос к NetworkManager без HTTP-запроса. Поэтому обнаружение смены сети может занять до 5 минут. После обнаружения смены подключений возвращается обычный интервал 20 секунд (или заданный `intervalSeconds`) до следующего `full`. При смене сети или переподключении проверка возобновляется; переподключение определяется по пути ActiveConnection, даже если профиль сети тот же. Изменение других активных подключений, например VPN, также возобновляет проверку. Собственные фоновые проверки NetworkManager эта настройка не отключает. После перезапуска плагина проверка выполняется заново.

При `none` проверка продолжает повторяться, пока есть активное подключение. После `full` истечение авторизации в той же сессии автоматически не обнаруживается: можно открыть страницу кнопкой или переподключиться. Уведомление не содержит кнопки действия; повторно открыть страницу можно виджетом на панели.

## Настройки

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `autoOpen` | `true` | Автоматически открывать браузер при обнаружении портала |
| `intervalSeconds` | `20` | Интервал проверки в секундах, минимум — 10 |

Отдельной графической страницы настроек пока нет. Параметры читаются из настроек плагина Noctalia.

## Обновление

Повторите команду установки. Предыдущая папка плагина сохраняется рядом с именем `captive-portal.backup.*`. После обновления перезапустите Noctalia.

## Диагностика

Проверьте, распознаёт ли NetworkManager страницу авторизации:

```bash
nmcli networking connectivity check
```

| Ответ | Поведение плагина |
| --- | --- |
| `portal` | Уведомление и открытие браузера, если включён `autoOpen` |
| `full` | Проверка интернета останавливается до смены активных подключений |
| `none` | Нет подключения; обнаружение следующего портала снова разрешено |
| `limited` / `unknown` | Автоматическое открытие не выполняется |

Если авторизация нужна, но результат — `limited` или `unknown`, проверьте connectivity checking в NetworkManager. VPN, собственный DNS и особенности сети могут мешать обнаружению или перенаправлению. Кнопка на панели позволяет открыть HTTP-страницу вручную.

Из локального клона можно проверить наличие файлов и зависимостей без установки:

```bash
bash install.sh --check
```
